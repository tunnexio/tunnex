A manager on a node with no gateway pod is idle: its state directory holds
heartbeat.json (state "idle") and no host-facts.json. That is normal; the
receipt is written only while a gateway runs on that node.

Install gateway releases only after every eligible DaemonSet pod is Ready.
Individual gateway uninstall must not remove this shared release. Remove it only
through the guarded cluster lifecycle after a cluster-wide readback proves that
no live Pod carries tunnex.io/host-posture-owner=true.
