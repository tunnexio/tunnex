## ⚠ A JUDGEMENT I MADE DURING THE BUILD — please rule on it

**UNDETERMINED is GROUPED into one counted line, not listed row by row.**

Every pre-`0069` node is undetermined, so on this rig **5 of 6 rows** would have been legacy gateways.
Listing each beside the declared agents would make the screen mostly legacy gateways **and would imply each
is a candidate agent — a stronger claim than "we do not know."**

⚠ It is still **rendered**, never hidden: the ruling was that it must not arrive as a blank, and a counted
line in its ruled words is not a blank. **Excluding them would assert they are not agents**, which is the
fact nobody has.
