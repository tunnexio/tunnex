# S20.5 — reproducible chart artifacts and real packaging evidence

Status: authorized blocker repair; no publication or live deployment.

The real host-posture chart gate failed a repeated archive comparison with the
repository-pinned Helm 3.18.4. Helm's archive writer uses the current time in
each tar entry; two raw `helm package` calls are not a reproducibility proof.
Source: [Helm 3.18.4 archive writer](https://github.com/helm/helm/blob/v3.18.4/pkg/chartutil/save.go).

Use one build-only packaging seam for release and private candidate charts:
real Helm validates/packages the chart into a private temporary directory;
a small Go standard-library tool validates regular, unique, bounded, safe
archive paths and re-encodes the exact file contents in sorted order with
canonical tar/gzip metadata. It extracts nothing to the filesystem and refuses
an existing output path. No chart template, schema, values, version, or rendered
resource is changed by normalization. Raw Helm archives are never compared as
if their wall-clock timestamps were immutable source facts.

Both the release workflow and candidate packager use this same seam. The
candidate repeats packaging and compares the real final bytes. Chart tests
prove metadata and rendered-resource parity before/after canonicalization.
Unit tests vary timestamps and entry order, prove content changes change bytes,
and refuse traversal, duplicate paths, non-regular entries and malformed input.

Finding 10's package fixture must run real Helm and Go. A small committed CLI
fixture is an orchestration substitute only; final qualification must also
build and inspect the actual Tunnex CLI. Archive inspection and explicit
secret sentinels replace grep over compressed bytes. Tests never publish or
authenticate. The deferred S20.5.2 rollout/publisher slice stays deferred.

Finding 9's missing ownership/downgrade witnesses are repaired separately with
actual template execution; source grep does not establish a refusal. The
committed live CRD lookup matrix remains mandatory and is not satisfied by

Independent read-only review requested cache isolation, portable-extraction
clarity, and real render parity. Packaging uses a task-selected Go cache (or a
private temporary cache by default), disables ambient GOENV/workspace and
automatic toolchain switching, and never resolves a dependency graph. CI and
this qualification lane use the repository-pinned Go 1.25.13 and Helm 3.18.4;
reproducibility is qualified for recorded toolchain versions, not across every
Go compression implementation. This tool canonicalizes repository-built Helm
archives; it is not a general cross-platform archive extractor or a guarantee
that arbitrary upstream chart filenames are portable. The four real charts
are compared file-by-file, via `helm show all`, and via actual rendered resources
before/after normalization. Existing output paths remain non-overwritable.
