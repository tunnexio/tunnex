# S12.1 — single binary and entitlements. Commit-one.

Makes the founder's band rulings real. **Nothing about a gateway limit exists in the product today** —
Community 1 · trial 2 · Starter 5 · Growth 20 · Scale unlimited are, until this story, only words.

---

## 1. Single binary — and it relicenses code, one way

Build tags go. `internal/enterprise/**` moves into the tree. **~1,784 lines move from the proprietary
source-available LICENSE to Apache-2.0.**

> ## ⛔ **ONE-WAY. Once released under Apache-2.0 it cannot be withdrawn from anyone who received it.**

**Founder-ruled.** Recorded as ruled rather than discovered, because §6.3 of the licensing paper flagged it
and the ordering question against copyright assignment is still open (`S12.1-licensing-decisions.md` §1a) —
**that question is a lawyer's and is not resolved by this story.**

## 2. Entitlements — ONE map, tier → features, as DATA

```go
license.Has(FeatSSO)          // yes
if edition == "enterprise"    // ⛔ never
```

⭐ **Moving a feature between tiers must be one line in the map.** That property is the whole reason for the
shape: §1 of the licensing model says the tier table may be revised in either direction, and a boundary
encoded as control flow can only be rewritten, never revised.

**Feature constants are named per capability, never reused** — same rule RBAC permissions follow, for the
same reason: a shared name makes two capabilities impossible to separate later.

## 3. Limits are checked at CREATION only

**Gateways and organizations.** A running gateway is never stopped; an existing org never disappears.

⛔ **This is not leniency — it is the rule the whole degradation model rests on**, and it is why the trial
band is 2 rather than 20 (`docs/laws.md`: a temporary grant of a create-time limit is a permanent grant of
everything created under it).

## 4. `tier` and `gateway_band` enter the wire format HERE

Not in S12.2. The precondition was recorded there: **a key must not assert a ceiling nothing enforces** —
that is the render-floor violation with a signature on it. This is the slice that makes it enforceable, so
this is the slice that adds it.

⚠ **The golden vector changes in both repos**, by hand, as designed.

## 5. Grace ladder

`valid → expired (warn, nothing stops) → 90-day grace (new principals refused) → after grace (gated
capabilities stop)`.

> ⛔ **A running VPN never stops. No human is ever blocked. Running gateways are never stopped.**

And the amendment already recorded: *"gated capabilities stop"* was written about capabilities that
**grant**. **A revocation mechanism is not a gated capability and never stops** — which is why IdP sync's
subtractive half keeps running.

## 6. The census replaces `test-editions`

`test-editions` proved a **compile-time** property: paid code absent from the open binary. A single binary
retires it. The replacement is source-derived and must be **proven to reject** — subject chosen by
capability, not by shape (`docs/laws.md`).

## 7. IdP-sync downgrade release — blocking, and built here

⛔ **No release path exists: membership freezes at the last sync and a leaver keeps access indefinitely.**

**Ruled: the subtractive half keeps running, the additive half stops.**

> ## ⭐ **A LICENCE MAY STOP GRANTING ACCESS. IT MUST NEVER STOP REMOVING IT.**

The gate lives at the seam, not at a call site — `onTrialApproved`'s two callers are the proof that a
call-site gate proves nothing about the other caller.

# What the build found (slices 7–9)

## 8. The SSO gate is only half of SSO — ⚠ DECIDE-ITEM, SURFACED NOT SETTLED

`requireSSOAdmin` guards **configuring** SSO and claiming a domain. It does **not** guard `StartSsoLogin`
or `SsoCallback`, and that absence is asserted by a test rather than left to memory.

> ## ⛔ **A LICENCE STATE MUST NEVER LOCK A HUMAN OUT OF THE PRODUCT.**

Gating the login path means an org whose only identity source is Google or Entra loses its own console 90
days after an expiry — **including the screen where a licence is installed.** The refusal would delete the
remedy along with the capability.

⚠ **AND IT STILL ENFORCES**, which is the part worth checking rather than believing: an unlicensed
deployment cannot configure SSO *at all*, so there is no config for the login path to use and nobody to log
in. Enforcement is complete for every new deployment. What survives an expiry is only what was already paid
for and set up — the create-time rule the whole model rests on (§3).

### ⛔ RULED (founder): keep it as built. `requireSSOAdmin` guards configuring SSO and claiming a domain; it does NOT guard login.

> ## ⛔ **A LICENCE GATE THAT PREVENTS INSTALLING A LICENCE IS A TRAP, NOT ENFORCEMENT.**

### ⛔ THE ALTERNATIVE READING — RECORDED AND REJECTED, WITH THE REASON

**Read literally, §5 says "after grace, gated capabilities stop", and SSO is a gated capability.** Someone
will reach this file, apply that sentence to the login path, and gate it. They will be reading the model
correctly and producing a trap.

**REJECTED BECAUSE:** the login path is the only way into the console for an org whose identity source is
Google or Entra — *including the screen where a licence is installed.* Gating it does not withhold a
capability, it **deletes the remedy**, and the customer who most needs to renew is the one who can no longer
reach the button. §5's sentence was written about capabilities that GRANT. Login does not grant; it admits.

⭐ **Same shape as the IdP-sync ruling one section over, and not a coincidence** — both are the model meeting
a mechanism people already depend on, and both resolve the same way.

## 9. Slice 9 needed no gate built. It needed the gate CALLED.

`WithProvisioningGate`, its three reds, and the D1 comment have existed since **S7.5.2**. All passed. And
`reconcileConfig` never called it, so `mayProvision()` saw a nil predicate and returned `true` — every
deployment provisioned unconditionally, underneath a green suite describing the gate in detail.

> ## ⛔ **A TEST THAT INJECTS THE GATE PROVES THE GATE. IT PROVES NOTHING ABOUT WHETHER ANYTHING INJECTS IT.**

⚠ **This is the third instance of producer-without-consumer this year and the first where the producer was a
SECURITY control.** The standing who-reads-this probe asks it of channel fields; it now has to be asked of
gates.

## 10. Two guards were found vacuous or nearly so, by different accidents

- **`policyhealth_structural_test.go`** scanned `../enterprise/policy`, which slice 1 dissolved. Its
  **vacuity floor is the only reason this failed** instead of passing over zero files. Re-pointed.
- **The enforcement census initially counted `license_handlers.go`** — which reads every ceiling *to display

## 11. Still open at the end of the build

### `build-editions` — ⛔ RULED: VACUOUS, AND **NOTHING REPLACED IT.** Say so plainly rather than delete it.

No non-test file carries `//go:build enterprise` any more, so both legs compile **identical code**. The
property it proved — *paid code is ABSENT from the open artifact* — **does not exist any more and has no
successor.** It was a compile-time guarantee, and a single binary cannot have one.

⚠ **This is NOT the same as `test-editions`, and the difference is the whole disposition.** `test-editions`
was retired by the single binary and **replaced**, by `entitlement_census_test.go` (is every capability
dispositioned) and `enforcement_census_test.go` (does anything refuse it). `build-editions` was retired and
replaced by **nothing** — the runtime censuses answer a different question, and no check anywhere asserts
absence, because nothing is absent.

⭐ **Recorded as a DELETION OF AN INVARIANT, which is what it is.** Deleting the target quietly would have
left a green suite and no record that the guarantee ever existed
(`docs/laws.md`: a reversed ruling should leave a NARROWER guard behind it, or an explicit note that none is
possible — never an absence).

⚠ `test-editions` is *not* vacuous — four `_test.go` files still carry the tag, and **both of this story's
invisible breaks were in them.** It is one deletion away from becoming so.

### `gateway_limit_reached` burns the join token — ⚠ REGISTERED, NOT FIXED

**Cause:** the ceiling is per-org, and the org is only known once `ConsumeJoinToken` has run. The grace check
was hoisted above the consume; this one cannot be.

**⛔ OPERATOR CONSEQUENCE, which is the part that must not be lost:** the refused enrolment **spends the
token**. After upgrading the licence or freeing a slot, the operator must **mint a fresh join token** — the
one in their hand is dead. Retrying with it produces `invalid_join_token`: **a second, unrelated error that
describes none of this**, sending them to look for a token problem that does not exist.

⭐ **So the refusal message now says it**, even though the burn itself is unfixed. Telling them costs one
sentence; not telling them costs a support round-trip at exactly the moment the product first says no.

## 12. ⛔ THE SAME GAP CAUGHT ME TWICE IN ONE STORY, AND THE SECOND TIME I HAD ALREADY WRITTEN THE LAW

Slice 5 broke `TestOrgLimitByEdition`; slice 8 broke `TestGetSsoConfigPayloadCarriesNoSecret`. Both live
behind `//go:build enterprise`. **Both were invisible to every check I ran** — a package test run does not
compile them, and `make test-editions` runs the OPEN leg first and exits on its failure, so the tagged leg
had never executed on this branch at all.

The second break is the worse one: `TestGetSsoConfigPayloadCarriesNoSecret` is the **blocking assertion that
SATISFIES the twice-deferred S4.5 secret-payload claim.** Gating `GetSsoConfig` turned it into a 403 check —
it would have kept "passing" as a security test that no longer read a payload.

> ## ⛔ **A GATE ADDED IN FRONT OF A HANDLER SILENTLY RE-AIMS EVERY TEST THAT CALLS IT.**
> **The test does not fail loudly at its own subject; it fails at the gate, or worse, passes at the gate.**

**The procedure, and it costs one command:** after adding any authorization or entitlement gate, run the
tagged leg explicitly and diff at **TEST** granularity against `origin/main`, never package granularity — a
new failure inside an already-red package moves a package-level diff by zero bytes.

```
go test -p 1 -tags enterprise ./... 2>&1 | grep -E "^\s*--- FAIL" | sed 's/ (.*//;s/^ *//' | sort
```

⚠ **And `-p 1` is not optional**: these are integration tests against one shared database, and running
packages concurrently produces failures that are pure interference.

## 13. Trial does not include SSO — checked, because §8's argument depends on it

§8 argues enforcement stays complete because an unlicensed deployment cannot configure SSO. That argument
would collapse if a **trial** could: configure SSO on a 30-day trial, let it lapse, and the ungated login
path works forever — *a temporary grant of a create-time limit is a permanent grant of everything created
under it*, the same law that set the trial band at 2.

`tierFeatures[TierTrial]` grants `multi_gateway` **and nothing else**. Trial cannot configure SSO, so §8
stands as written. **Recorded because the check mattered, not because it found something.**
