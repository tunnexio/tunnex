## Integration decisions

- Remove the transferred desktop files, including S20.5-added files that a Git
  modify/delete merge alone would leave behind. No `apps/client`, `apps/helper`,
  desktop renderer or desktop bridge remains in this server checkout.
- Preserve release-version immutability and anonymously-pullable publication
  guards. Remove only dependencies on the retired desktop CI job, including
  the new S20.5 release guard, and update matching contract assertions.
- Preserve S20.5 project-specific test storage variables; do not restore
  default/shared Compose storage while resolving Makefile conflicts.
- API, node, CLI, operator, OpenAPI and chart source are byte-unchanged by this
  integration relative to `33661ca`. Existing evidence retains its original
  source/digest and limitations; no cloud deployment or installed-client change
  occurred here.
- Historical S20.5 desktop design records remain in this repository for
  provenance. New desktop implementations and tests belong to the client repo.
