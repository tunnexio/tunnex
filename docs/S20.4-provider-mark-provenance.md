# S20.4 provider-mark provenance and release check

Status: local-preview record; re-check before any commit or release.

The provider cards render locally vendored provider artwork in
`apps/web/src/components/ProviderMarks.tsx`. The three cloud marks are data
images, so neither the browser nor Electron renderer makes a runtime request to
a provider CDN. The self-managed mark remains a neutral local server-rack glyph
because it is not a cloud provider.
